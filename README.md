# AgroVet Field System

เว็บแอปตามไฟล์ Stitch ที่แนบมา ประกอบด้วย 4 หน้าหลัก และเริ่มต้นโดยไม่มีข้อมูลตัวอย่างเพื่อให้ผู้ใช้กรอกข้อมูลเอง:

- `index.html` — แดชบอร์ด
- `cases.html` — เคสรักษาและไทม์ไลน์การรักษา
- `medicine.html` — ยาและเวชภัณฑ์
- `livestock.html` — สัตว์และคอก

เปิดไฟล์ `index.html` ได้โดยตรงในเบราว์เซอร์ หรือรันผ่าน local web server หากต้องการให้การโหลดฟอนต์และรูปภาพภายนอกทำงานได้สมบูรณ์

รองรับวันที่เกิด วันที่ตาย วันที่แจ้งเคส การบันทึกยา และแจ้งเตือนยาใกล้หมดตามเกณฑ์ขั้นต่ำที่ตั้งไว้ ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์นั้น
